# Midas Bot - Sistema Experimental de Trading Algorítmico

## Descripción del Proyecto
Sistema de desarrollo propio para análisis cuantitativo de mercados financieros usando Deep Learning. 
**Inicio de desarrollo**: Abril 2026

## Propósito
Este repositorio documenta el proceso de investigación y desarrollo de estrategias algorítmicas. 
**Uso exclusivo**: Experimentación personal en cuentas DEMO. No destinado a producción ni asesoría a terceros.

## Arquitectura del Sistema
- `bot.py`: Ejecutor principal de la lógica de trading
- `entrenar.py`: Pipeline de entrenamiento de modelos PyTorch
- `gestor_riesgo.py`: Módulo de control de riesgo y position sizing
- `backtest.py`: Validación histórica de estrategias
- `modelo.py`: Definición de arquitecturas de redes neuronales

## Advertencia de Riesgo
El trading algorítmico implica riesgo de pérdida de capital. Este software es experimental y no se ha sometido a auditorías externas. Todo resultado pasado en backtesting no garantiza rendimiento futuro.
